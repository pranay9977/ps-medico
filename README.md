# PS Medico

Offline medicine alternative finder for India: type any medicine name (any company), any salt or a symptom, and see the same-salt alternatives from 74 rated Indian and global makers - with prices, per-unit costs, maker trust scores built only from public regulatory records (US FDA warning letters, import alerts, recalls), and offline safety tools (medicine cabinet, interaction checks, pregnancy guidance, Hindi mode and more). One file, works fully offline, no installation, no account, no tracking.

Official link: https://pranay9977.github.io/ps-medico/
